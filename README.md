# test-axe — git-lab

Repo ديال التمرين باش نتعلم **Git** ونمنيبولي ملفات **JSON**.

## المحتوى
- `data.json` — ملف JSON فيه لائحة ديال المنتجات للتمرين.
- `.gitignore` — الملفات اللي خاص Git يتجاهلها.

## أوامر Git الأساسية اللي غادي نتعلمو
- `git status` — شنو تبدّل.
- `git add` — نزيدو الملفات للـ staging.
- `git commit` — نسجلو snapshot.
- `git branch` / `git switch` — نخدمو على فروع.
- `git merge` — ندمجو الفروع.
- `git log` — التاريخ ديال الـ commits.
